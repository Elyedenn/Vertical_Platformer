## 🎮 Vertical Platformer

A simple Unity 2D platformer project implementing basic movement and auto-jump mechanics.

## 📌 Features
- Player movement
- Auto jump system
- Basic platformer mechanics

## 🛠 Tech
- Unity
- C#

## 🚀 How to Play

### Mobile (APK)
- Auto jump
- Touch screen: move left/right

### PC (Prototype)
- Arrow keys: move
- Space: jump
